# Ailyt ERP — Frontend

React + TypeScript + Vite frontend for the Ailyt ERP system — a role-based web app for Ailyt's computer training institute and cyber café.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS

## Setup
```bash
npm install
cp .env.example .env   # set VITE_API_URL to your backend URL
npm run dev
```
